# Kids IP game — playable concept + scope

Static site, no build step.

- **Play the sandbox**: textless, no-fail play in a kitchen and garden. Drag the two placeholder friends, feed them, tickle them, sit them on chairs. Discoveries earn stickers; four stickers unlock the garden, where kids plant, water, and pick carrots that show up in the fridge. A grown-up gate (word-based math question) guards settings and the demo purchase. Sound is synthesized with Web Audio, no audio files.
- **Scope & cost**: an indicative estimator. Every option changes budget, timeline, cost drivers, and team.
- **Plan & roles**: stages, who does what, technology.
- **Kids-safe by design**: store and legal rules, earning models, risks, and how v1 is built to grow.

Run: `npm start` → http://localhost:3000 · Deploy: `npm run deploy` or import into Vercel with the "Other" preset.
Characters are placeholders; the client's IP replaces them.
